七、预结算提交逻辑更新

函数签名变更

版本函数签名说明
修改前 const confirmPreSettle = () => { ... } 无参数，默认全部结算
修改后 const confirmPreSettle = (settleType = '全部结算') => { ... } 接收结算类型参数，默认值「全部结算」

核心代码

const confirmPreSettle = (settleType = '全部结算') => {
  filteredPreSettleList.value.forEach(settle => {
    const target = memberList.value.find(m => m.idCard === settle.idCard)
    if (target) {
      target.preSettleAmount = Number(settle.preSettleAmount || 0)
      target.remark = settle.remark || ''
      target.bankAccount = settle.bankAccount || ''
      target.bankType = settle.bankType || ''
      target.bankBranch = settle.bankBranch || ''
      target.bankPhone = settle.bankPhone || ''
      target.bankCode = settle.bankCode || ''
      target.isAccountOpened = !!settle.isAccountOpened
      target.settleType = settleType  // ← 新增：写入结算类型
      if (preSettleForm.needWorkerConfirm && target.preSettleAmount > 0) {
        target.workerConfirmStatus = '待确认'
      } else if (!preSettleForm.needWorkerConfirm) {
        target.workerConfirmStatus = '无需确认'
      }
    }
  })
  preSettleVisible.value = false
  confirmSettleSearch.name = ''
  buildConfirmSettleList()
  if (preSettleForm.needWorkerConfirm) {
    ElMessage.success(`预结算已提交（${settleType}），等待灵工确认`)
  } else {
    ElMessage.success(`预结算已提交（${settleType}）`)
    onTabChange('confirm-settle')
  }
}
✅ 成功提示消息包含结算类型：
• 需灵工确认：预结算已提交（全部结算），等待灵工确认
• 无需确认：预结算已提交（部分结算）

附录：结算计算公式

项目公式示例（预结算金额 6000）
增值税及附加 预结算金额 × 1%（金额 > 1000 时征收，否则为 0） 6000 × 1% = 60.00
代扣个税 (预结算金额 - 5000) × 0.8 × 3%（≤5000 时为 0） (6000 - 5000) × 0.8 × 3% = 24.00
实付金额 预结算金额 + 增值税及附加 6000 + 60 = 6,060.00
到账金额 预结算金额 - 代扣个税 6000 - 24 = 5,976.00
